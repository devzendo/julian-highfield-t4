# julian-highfield-t4

## What is this?

This is the source code to Julian Highfield's Transputer emulator,
from 1997. Original source downloaded from https://web.archive.org/web/20160331233541/http://spirit.lboro.ac.uk/emulator.html
and committed here with only the necessary modifications to build it under
macOS Tahoe (Apple Silicon).

## Other Transputer Emulators

I'm using various emulators to check the behaviour of my emulator
from https://github.com/devzendo/transputer-emulator against other emulators.

There is also a significant evolution of this codebase by Andras Pahi,
at https://github.com/pahihu/t4, and Gavin Crate's jserver emulator (Win32
only) from https://sites.google.com/site/transputeremulator/Home/jserver/installation-instructions
which started as a port of this codebase.
